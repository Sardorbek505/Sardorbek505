## 🪐 About

I design and ship complete products end to end — solo. Not "I code the feature someone else specced," but **I own the whole thing**: architecture, database, UI, integrations, deploy, and the two-week-later 2am bug fix.

Most of my recent work is **AI-agent-driven engineering** — I work alongside Claude Code as a real collaborator across the full lifecycle: planning, implementation, security review, and production verification via live browser testing before anything ships. That workflow is how a handful of production SaaS products below went from idea to live in weeks, not quarters.

- 🏗️ Currently building **[Brona](https://github.com/Sardorbek505/zapis)** — white-label online booking SaaS for local service businesses
- 💬 Deep in **Telegram Bot API, webhooks, and Supabase/Postgres** as my default backend stack
- 🎙️ Shipped a real-time **voice AI assistant** on the Gemini Live API
- 📍 Based in Shymkent, Kazakhstan — building for the local market first
